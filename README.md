# 📚 Algoritmos y Estructuras de Datos — UTN

Este repositorio contiene los Trabajos Prácticos desarrollados durante la cursada de la materia **Algoritmos y Estructuras de Datos** en la carrera Ingeniería en Sistemas de Información.

---

## 🛠️ Tecnologías utilizadas
* **Lenguaje:** Python 3
* **Conceptos clave:** Lógica de programación, estructuras de datos, modularización y algoritmos de ordenamiento/búsqueda.

---

## 📂 Contenido del repositorio

### 1. 🃏 [Blackjack (2022)](./Tp_Black_Jack_(2022).py)
* **Descripción:** Juego de cartas Blackjack ejecutable por consola.
* **Características:** Implementación de reglas del juego, conteo de puntos y lógica de turnos.

### 2. 📊 [Gestión de Proyectos](./TP_Gestion_de_Proyectos)
* **Descripción:** Sistema enfocado en la administración, registro y seguimiento de proyectos/tareas.

### 3. 🚗 [Servicio de Peajes](./TP_Servicio_Peajes)
* **Descripción:** Sistema de simulación para el registro y cobro de vehículos en estaciones de peaje.

### 4. 🏥 [Gestión de Tratamientos Médicos](./Gestion_Tratamientos_Medicos)
* **Descripción:** Sistema enfocado en la administración, registro, control y seguimiento de tratamientos médicos.
